# Overview #
* The Krista extensions connects to the Azure Authentication for authenticating Microsoft users.

## Prerequisite
* Before proceeding with setup process, ensure you have the necessary access and privileges.
refer: [Authentication Setup](pages/obtainingClientIDClientSecret.md)

## Setup
* Once you've clientId, clientSecret and tenantId, you can configure the extension with these values.

  <img src="docs/_media/setup.png" width="450" height="400"/>

* Enable **Trust extension** flag as shown in image.
* Next Click on validate to validate the configuration.
